Overview Three screens What a code can open Privacy

The app is a pocket workspace for codes a business actually hands to someone: the website, the menu, a WhatsApp chat, an email address, a contact card, or the shop Wi-Fi. Create the code, save it, and the next time it is one search away.

Scanning uses the camera for a live code or the photo library for a picture already saved. A web address in the code is recognized, and the app includes a risk check before you follow it. Generated codes can be saved back to the gallery.

The three screens

Scan

Read a code

Point the camera, or choose an image you already have. The app reads the payload and checks a web address before you open it.

Create

Make a code

Build a code for a page, a menu, WhatsApp, email, a contact, or Wi-Fi. One tap prepares it for the table, the counter, or a printed card.

Library

Keep it

Created codes and scans sit together. Mark favorites, group them, and search when you need the same code again.

What a code can open

Website

Send a customer to a page you already have.

Menu

Put the menu on the table instead of reprinting it.

WhatsApp and email

Start a chat or a message from the scan.

Contact and Wi-Fi

Share a card, or the network, without typing it out.

Privacy

The library does not go to a Business QR server

Scanned content, generated codes, favorites, and the photos used to read a code stay on the phone. Uninstalling the app removes that library. The app does not ask you to create a profile, and it does not run its own analytics or crash reporting.

The app does show advertisements through Google AdMob, as banner ads and ads when the app opens. Google may use an advertising identifier, IP address, device type, and ad interactions to serve those ads. Personalized ads can be turned off in the phone's Google ads settings. Creating and reading codes does not depend on sending the QR itself anywhere.

Permissions

Camera and photos, for the job

The camera is used to scan a code in front of you. Photos are used to scan a code from a saved image and to store a code you generated. Those permissions are not used to upload your pictures.
