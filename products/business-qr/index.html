A long link gets mistyped, the printed menu is already out of date, and the Wi-Fi password lives on a scrap of paper. A code fixes that handoff. The next problem is losing the code you already made, and making it again from memory.

Business QR keeps created codes and scans in one library on the phone, so the next time you search instead of starting over. Scanning uses the camera, or a picture already in the gallery. A web address is recognized, and the app includes a risk check before you follow it. Generated codes can be saved back to the gallery. No account is required. The app shows Google ads.

When the code is needed

Received

Someone hands you a code

Point the camera, or choose an image you already saved. The app reads it and checks a web address before you open it.

Handoff

You are about to spell it out

Build a code for a page, a menu, WhatsApp, email, a contact, or Wi-Fi. Keep it for the table, the counter, or a printed card.

Again

You made this code last month

Created codes and scans sit together. Mark favorites, group them, and search when the same code is needed again.

What people ask you to repeat

The page address

The page already exists. The customer should not have to type it.

The menu

Reprint the card when a price changes, or point a code at the current menu.

WhatsApp and email

A number read aloud gets one digit wrong. A scan opens the chat or the message.

A contact or the Wi-Fi

The password and the contact card should not depend on a good memory.

Privacy

A saved code only helps if it stays put

The library solves the lost-code problem on the phone itself. Scanned content, generated codes, favorites, and the photos used to read a code stay there. Uninstalling the app removes that library. The app does not ask you to create a profile, and it does not run its own analytics or crash reporting.

The app does show advertisements through Google AdMob, as banner ads and ads when the app opens. Google may use an advertising identifier, IP address, device type, and ad interactions to serve those ads. Personalized ads can be turned off in the phone's Google ads settings. Creating and reading codes does not depend on sending the QR itself anywhere.

Permissions

Camera and photos, for the job

The camera is used to scan a code in front of you. Photos are used to scan a code from a saved image and to store a code you generated. Those permissions are not used to upload your pictures. The current build is on Google Play.
